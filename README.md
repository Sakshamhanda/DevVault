# 🚀 DevVault - GitHub Profile Finder

DevVault is a sleek and responsive web application built with **HTML5, CSS3, and JavaScript (Vanilla)** that allows users to search for GitHub profiles and view key profile statistics and details in real-time using the **GitHub REST API**.

---

## 📸 Preview

Search any GitHub username to instantly retrieve:

- Profile Avatar & Username
- Bio description
- Follower, Following & Repository counts
- User Location

---

## ✨ Features

- 🔍 **Live Search**: Fetch any public GitHub user's profile with a simple search.
- ⚡ **Asynchronous Data Fetching**: Powered by JavaScript's Fetch API.
- 🎨 **Clean & Responsive UI**: Card-based modern design tailored for all screen sizes.
- 🔗 **Direct Profile Link**: Quick navigation link to the user's official GitHub page.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic markup and page structure.
- **CSS3**: Custom modern styling, flexbox layout, and card design.
- **JavaScript (ES6+)**: DOM manipulation and API integration.
- **GitHub REST API**: Source for dynamic profile data.

## 🚀 Getting Started

To run this project locally on your machine:

1. **Clone the repository**:

   ```bash
   git clone https://github.com/Sakshamhanda/DevVault.git
   ```

2. **Navigate to the project folder**:

   ```bash
   cd DevVault
   ```

3. **Open the project**:
   - Open `index.html` directly in your favorite browser, or
   - Use VS Code Live Server extension: Right-click `index.html` ➔ **Open with Live Server**.
